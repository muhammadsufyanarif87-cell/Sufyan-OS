03 — UPGRADE GUIDE

Recommended PC parts

CPU / Processor

Practical target: 4 physical cores minimum, 6 cores better.

Examples: Intel Core i5 8th Gen or newer, or a compatible AMD Ryzen 5.

Check: lscpu

RAM

8 GB target; 16 GB better for Studio and multitasking.

DDR3, DDR4 ya DDR5 motherboard ke mutabiq choose karo.

Check: sudo dmidecode -t memory

Graphics Card

Linux Studio target: OpenGL 4.4 minimum; Vulkan 1.4 recommended.

Player target: OpenGL ES 3.0; Vulkan 1.1 recommended.

Check: glxinfo -B

SSD

256 GB SSD practical starting target. 512 GB gives more project space.

Check: lsblk

Motherboard

CPU socket, RAM generation, RAM slots and maximum supported RAM check karo.

Check: sudo dmidecode -t baseboard

Power Supply

GPU ke recommended PSU wattage aur PCIe power connectors check karo.

Check: PSU label physically dekho. Software se exact PSU model detect nahi hota.

04 — COMMAND CENTER

Hardware checking commands

CPU model, cores and threads

lscpu

RAM and memory slots

free -h sudo dmidecode -t memory

Motherboard model

sudo dmidecode -t baseboard

GPU and driver

lspci -nnk | grep -A4 -Ei 'VGA|3D|Display'

OpenGL

glxinfo -B

Vulkan

vulkaninfo --summary

CPU SSE instructions

grep -m1 '^flags' /proc/cpuinfo

Storage

lsblk -o NAME,SIZE,MODEL,TYPE

Kernel

uname -r
Important upgrade warning

CPU, RAM aur GPU khareedne se pehle motherboard model, CPU socket, RAM generation, PSU wattage aur case size check karo. Har motherboard har processor ya graphics card support nahi karta.

Detection note: OpenGL ES aur Vulkan agar install nahi hain ya driver unhein expose nahi karta to checker "not detected" show karega. Iska matlab hamesha hardware failure nahi hota.
